# 🤖 ClonGPT

ClonGPT is a custom ChatGPT clone that uses the OpenAI API to power natural language conversations. Built with a unique design called **"Rain of Coding"**, this project combines both front-end and back-end technologies, with secure `.env` integration for API key management.

## 🌐 Live Demo

> 🚀 [ClonGPT Live Preview](https://dat1n.github.io/clonegpt/)

---

## 📁 Project Structure

clongpt/
│
├── frontend/ # UI with custom design

│ ├── public/

│ ├── src/

│ └── index.html

│
├── backend/ # Handles API requests

│ └── server.js (or app.py)

│ └── .env # Stores API keys securely

├── package.json # Project config (Node.js) 

└── README.md



## 🛠️ Tech Stack

| Layer      | Tech                             |
|------------|----------------------------------|
| Frontend   | HTML / CSS / JavaScript |
| Backend    | Node.js  |
| API        | OpenAI GPT API                   |
| Styling    | Custom CSS — "Rain of Coding"    |
| Security   | `.env` for API key management    |
